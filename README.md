# SPA App (React)

このプロジェクトは、Qiita APIを利用したシングルページアプリケーション(SPA)です。記事一覧の取得と詳細表示が可能です。

## 概要

- **一覧表示ページ**: Qiita APIを利用して記事一覧を表示します。
- **詳細表示ページ**: 記事を選択すると、その詳細情報が表示されます。
- **APIキー入力**: 設定ボタンからAPIキーを入力し、保存できます。

## URL構成

- 一覧表示ページ: [http://localhost:3000/](http://localhost:3000/)
- 詳細表示ページ: [http://localhost:3000/[id]](http://localhost:3000/[id])
  (ここで`[id]`は記事のIDです)

## 使用方法

1. プロジェクトのディレクトリに移動します。

   ```bash
   cd spa-app-react

2. 以下のコマンドでサーバーを起動します。

   ```bash
   yarn start

3. ブラウザで http://localhost:3000/ を開きます。

4. "apiキー入力"ボタンからQiitaトークンを入力します。

5. "保存"ボタンを押すと、記事一覧が表示されます。

6. 記事をクリックすると、その詳細ページに遷移します。
